# Building an Honest Nutrition E-Commerce Platform on AWS

#### Overview

The workshop starts with access control and Terraform, then deploys React, Spring Boot, and PostgreSQL on AWS. The dev environment runs in Singapore, while Bedrock and Guardrail calls run in Tokyo.

Steps use the project repository’s configuration and commands. Evidence is supplied alongside each step and test/cost figures include their measurement dates.
